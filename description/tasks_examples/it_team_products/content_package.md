NovaCore — внутренняя IT-команда, которая создаёт платформы для инженерных подразделений компании. Миссия команды — сокращать время от идеи до стабильного запуска продукта, снижать операционную нагрузку и делать знания доступными для всех разработчиков.

Аудитория презентации: продуктовый комитет и руководители инженерных направлений.

## Продукты

### PulseOps

Платформа мониторинга и управления инцидентами для SRE-команд и линий поддержки. PulseOps используют 74 команды. После внедрения среднее время восстановления сервиса сократилось с 52 до 32 минут.

### ReleaseRail

Платформа доставки программного обеспечения для продуктовых команд. Через ReleaseRail проходит 3 200 релизов в месяц, доля успешных развёртываний составляет 99,5%.

### AtlasMind

AI-база инженерных знаний для разработчиков и аналитиков. AtlasMind объединяет 24 000 документов и автоматически закрывает 72% пользовательских вопросов.
