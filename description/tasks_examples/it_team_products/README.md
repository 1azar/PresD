# NovaCore — тестовый пример на 10 слайдов

Набор предназначен для ручного запуска через веб-интерфейс PresD. Все данные, персонажи и портреты синтетические.

1. Загрузите шаблон `description/VK Tech шаблон.pptx` и дождитесь завершения его анализа.
2. В поле «Бриф» вставьте содержимое `brief.txt`.
3. В поле «Текст» вставьте содержимое `content_package.md`.
4. Добавьте все пять PNG из каталога `portraits/`. Три явно названных набора будут синтезированы и отмечены в замечаниях. Для проверки режима с авторитетными данными вместо синтеза дополнительно приложите `structured_assets.json`.
5. Установите количество слайдов `10—10`.
6. Оставьте быстрый режим выключенным и запустите генерацию.

Ожидаемая структура: обложка, портфель продуктов, линейный график, кольцевая диаграмма, таблица и пять персональных слайдов. Для каждого профиля должны использоваться имя, роль, опыт, зона ответственности и портрет с соответствующим исходным именем файла.
