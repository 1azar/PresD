# Документация PresD

Этот каталог содержит техническую и эксплуатационную документацию проекта.
Корневой README предназначен для первого знакомства, а здесь подробно описаны
запуск, устройство и сопровождение системы.

## Принципы документации

- README даёт короткий путь от знакомства до первого запуска.
- Каждый факт описывается в одном каноническом документе; остальные страницы
  ссылаются на него.
- Команды выполняются из корня репозитория, если явно не указано обратное.
- Изменение поведения, конфигурации или интерфейса сопровождается обновлением
  соответствующей страницы в том же Pull Request.
- Секреты, реальные пароли, API-ключи и пользовательские материалы в документацию
  не добавляются.
